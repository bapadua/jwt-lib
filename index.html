Fundamentos

Conceitos Abordados na Implementação

Segurança em Tipos Fortes

Separação estrita de SecretKey e chaves assimétricas para mitigar Algorithm Confusion, verificação em tempo constante contra timing attacks e rejeição estrita de alg=none.

Recursos Nativos da JVM

Uso das bibliotecas criptográficas padrão (java.security) e do cliente HttpClient HTTP/2 nativo para resolução de chaves remotas.

JWKS & Rotação de Chaves

Provedor com cache configurável (TTL) e suporte a Refresh-on-Miss para absorver rotações de chave em IdPs (Keycloak, Auth0, Cognito) de forma transparente.

Algorithm Pinning

Restrição explícita no parser dos algoritmos aceitos para evitar falsificação por rebaixamento de cifra ou modificação maliciosa de cabeçalhos.

Imutabilidade & Fluent API

Objetos Jwt imutáveis pós-validação com cópias defensivas de coleções e arrays, com builders e parsers fluentes.

Sealed Interfaces

Uso de sealed interface para restringir as implementações criptográficas (Signer, Verifier) estritamente ao escopo interno do pacote.

Exemplos de Utilização

HmacExample.java — Assinatura e Validação Simétrica
import com.github.bapadua.labs.jwt.Algorithm; import com.github.bapadua.labs.jwt.Jwt; import com.github.bapadua.labs.jwt.Jwts; import javax.crypto.spec.SecretKeySpec; import java.nio.charset.StandardCharsets; // 1. Chave secreta com tipagem forte (mínimo 256 bits para HS256) SecretKeySpec secretKey = new SecretKeySpec( "sua-chave-secreta-de-estudo-com-pelo-menos-256-bits!".getBytes(StandardCharsets.UTF_8), "HmacSHA256" ); // 2. Construção e assinatura do token String token = Jwts.builder() .alg(Algorithm.HS256) .signWith(secretKey) .subject("usuario-123") .issuer("https://auth.meudominio.com") .audience("api://minha-api") .issuedNow() .expiresInSeconds(3600) // 1 hora .id() // Gera UUID v4 automático para 'jti' .claim("role", "ADMIN") .compact(); // 3. Validação com verificação estrita e Algorithm Pinning Jwt jwt = Jwts.parser() .verifyWith(secretKey) .requireAlgorithm(Algorithm.HS256) .requireIssuer("https://auth.meudominio.com") .requireAudience("api://minha-api") .parse(token); System.out.println("Subject: " + jwt.getSubject()); System.out.println("Role: " + jwt.getStringClaim("role"));
RsaExample.java — Assinatura com PrivateKey e Verificação com PublicKey
import com.github.bapadua.labs.jwt.Algorithm; import com.github.bapadua.labs.jwt.Jwt; import com.github.bapadua.labs.jwt.Jwts; import java.security.KeyPair; import java.security.KeyPairGenerator; // Gera par de chaves RSA (2048 bits) KeyPairGenerator kpg = KeyPairGenerator.getInstance("RSA"); kpg.initialize(2048); KeyPair keyPair = kpg.generateKeyPair(); // 1. Emissor: Assina com a Chave Privada String token = Jwts.builder() .alg(Algorithm.RS256) .signWith(keyPair.getPrivate()) .keyId("auth-key-01") .subject("usuario-corporativo") .expiresInSeconds(1800) .compact(); // 2. Consumidor: Valida exclusivamente com a Chave Pública Jwt jwt = Jwts.parser() .verifyWith(keyPair.getPublic()) .requireAlgorithm(Algorithm.RS256) .requireKeyId("auth-key-01") .parse(token); System.out.println("Validado com sucesso para: " + jwt.getSubject());
RemoteJwksExample.java — Consulta de Chaves em Endpoints OIDC
import com.github.bapadua.labs.jwt.Algorithm; import com.github.bapadua.labs.jwt.Jwt; import com.github.bapadua.labs.jwt.Jwts; import com.github.bapadua.labs.jwt.internal.jwk.RemoteJwksKeyProvider; import com.github.bapadua.labs.jwt.internal.jwk.http.HttpJwksFetcher; import java.time.Duration; // 1. Fetcher HTTP/2 nativo com timeouts definidos HttpJwksFetcher fetcher = HttpJwksFetcher.of( "https://auth.meudominio.com/realms/master/protocol/openid-connect/certs", Duration.ofSeconds(3), Duration.ofSeconds(5) ); // 2. Provedor com cache e recarregamento automático (TTL 10 min) RemoteJwksKeyProvider keyProvider = RemoteJwksKeyProvider.of(fetcher, Duration.ofMinutes(10)); // 3. Validação resolvendo a chave pública dinamicamente pelo 'kid' Jwt jwt = Jwts.parser() .keyProvider(keyProvider) .requireAlgorithm(Algorithm.RS256) .requireIssuer("https://auth.meudominio.com/realms/master") .clockSkewSeconds(60) .parse(tokenRecebido); System.out.println("Usuário validado via JWKS: " + jwt.getSubject());
SecurityFeatures.java — Validações de Claims e Tolerância Temporal
// Validação de claims e tolerância no parsing Jwt jwt = Jwts.parser() .verifyWith(publicKey) // Algorithm Pinning: aceita somente o algoritmo esperado .requireAlgorithm(Algorithm.RS256) // Validação de Emissor (iss) e Audiences (aud) .requireIssuer("https://auth.exemplo.com") .requireAudience("api-faturamento", "api-gateway") // Validação do tipo (typ) no Header conforme RFC 9068 .requireType("JWT") // Key ID específico (kid) .requireKeyId("key-2026-v1") // Clock Skew: tolerância para pequenos atrasos de relógio (ex: 30s) .clockSkewSeconds(30) .parse(token);
